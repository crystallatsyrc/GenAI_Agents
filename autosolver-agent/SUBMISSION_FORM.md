## Work Introduction

An offline strategy-search agent for stochastic courier assignment. It builds a portfolio of greedy, beam, fanout, reassignment, and local-exchange solvers, evaluates each candidate plan under one objective, and returns the best upload-safe `solver.py` within the time budget.
